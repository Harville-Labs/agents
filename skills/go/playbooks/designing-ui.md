### Designing UI

**You own how it looks and feels, not only that it works.** The screenshots are the proof. The code alone is not.

1. Load the **giga-ui** skill and read its `references/style.md`.
2. Write the brief from giga-ui's prompt-expansion template: layout pattern, theme, one accent, type, realistic data, motion, states. Name the reference image you're matching.
3. Copy giga-ui Workflow steps 1 to 12 into the todo list and build to the brief. Use the repository's component library and stack rules first, and translate giga-ui's recipes into them.
4. Run giga-ui's verification round (`references/qa.md` §9.5) through the **control-ui** skill. Pass or fail each check item. At most 2 fix rounds.
5. Run **Opening a PR** with the desktop and mobile screenshots in the PR body.

**Reply:** the brief, the reference image matched, the screenshots, and every check item that still fails.
